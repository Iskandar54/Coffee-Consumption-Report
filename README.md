### Отчет о потреблении кофе

## Скачивание
git clone [https://github.com/Iskandar54/Coffee-Consumption-Report.git](https://github.com/Iskandar54/Coffee-Consumption-Report.git)

cd Coffee-Consumption-Report

## Установка зависимостей
pip install -r requirements.txt

## Запуск
python main.py --files data.csv --report median-coffee

## Пример запуска
python main.py --files math.csv physics.csv programming.csv --report median-coffee
